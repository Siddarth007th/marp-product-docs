# Algorithmic Complexity  
### (Requirement: Mathematical equation)

The time complexity of a divide-and-conquer algorithm such as Merge Sort is:

\[
T(n) = 2T\left(\frac{n}{2}\right) + n
\]

By the Master Theorem:

\[
T(n) = O(n \log n)
\]
